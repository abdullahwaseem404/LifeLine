# 📊 LifeLine - Suicide Data Analysis

A complete data analytics project that explores global suicide trends using **SQL and Power BI**. This project focuses on identifying patterns across **years, countries, gender, age groups, and generations**.

---

## 📌 Project Overview

This project analyzes worldwide suicide data to uncover:

* 📅 Yearly trends and growth patterns
* 🌍 Country-wise suicide distribution
* 👨‍👩‍👧 Gender-based comparison
* 🎯 Age group & generation insights
* 💰 Relationship with GDP per capita

---

## 📊 Key Insights

* 📈 Suicide rates peaked around the mid-1990s and show fluctuations over time.
* 👨 Males account for ~77% of total suicides.
* 🌍 Europe and Asia show higher concentrations.
* 👴 Older generations (Boomers & Silent) have higher suicide counts.
* 💰 GDP per capita shows correlation with suicide rates in some regions.

---

## 🌍 Features of Dashboard

* 🔎 Interactive filters (Country, Age Group)
* 📊 KPI Cards:

  * Total Suicides (7M)
  * GDP per Capita (469M)
  * Avg Suicide Rate (12.82)
* 🗺️ Global Map Visualization
* 📉 Trend Line Analysis
* 🧩 Gender & Generation Breakdown
